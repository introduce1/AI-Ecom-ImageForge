# AI-Ecom-ImageForge（AI电商影像工坊）

一个基于AI的智能图像处理Web应用，提供多种图像编辑和生成功能，特别针对电商图片处理场景优化。

## 🚀 功能特性

### 核心功能
- **文字修改** - 智能识别并修改图片中的文字内容，支持精确位置编辑
- **尺寸编辑** - 精确裁剪和调整图片尺寸，支持多种预设规格和自定义尺寸
- **批量Logo编辑器** - 专业的Logo添加工具，支持多平台、多款式、多尺寸规格
- **产品抠图** - 自动识别并提取产品主体，去除背景
- **背景替换** - 一键替换图片背景，支持批量处理
- **高清放大** - AI智能放大图片保持清晰度
- **一键扩图** - 智能扩展图片边缘内容
- **产品迁移** - 将产品迁移到不同场景，支持批量处理
- **水印去除** - 智能去除图片水印
- **去瑕疵** - 自动修复图片瑕疵和缺陷

### 批量Logo编辑器特色功能
- **多平台支持** - 支持天猫、京东、拼多多等电商平台
- **多款式选择** - 普通款、宝可梦联名款、茶具款等多种款式
- **尺寸规格管理** - 支持800×800、750×1000、1200×N等电商标准尺寸
- **智能尺寸匹配** - 自动检测上传图片尺寸并匹配对应规格
- **Logo位置调整** - 可视化拖拽调整Logo位置和大小
- **批量处理** - 支持一次上传多张图片批量添加Logo
- **实时预览** - 画布实时预览，支持缩放和拖拽
- **打包下载** - 批量处理结果一键打包下载

### 尺寸编辑器特色功能
- **多种裁剪模式** - 自由裁剪、自定义尺寸、平台预设规格
- **实时预览** - 裁剪区域实时显示，支持调整
- **精确控制** - 支持像素级精确调整
- **比例锁定** - 支持固定宽高比裁剪

### 文字编辑器特色功能
- **OCR识别** - 自动识别图片中的文字
- **精确编辑** - 支持指定区域文字修改
- **样式保持** - 保持原文字样式和背景
- **多文字处理** - 支持一次修改多个文字区域

### 批量处理功能
- **批量背景替换** - 最多支持8张图片批量替换背景
- **批量产品迁移** - 批量将产品迁移到场景图
- **进度跟踪** - 实时显示批量处理进度
- **结果管理** - 批量结果预览和打包下载

### 其他特色功能
- **AI对话助手** - 通过自然语言指令处理图片
- **历史记录** - 自动保存所有处理结果，支持查看和重新下载
- **拖拽上传** - 支持拖拽文件上传
- **实时预览** - 处理前后对比预览
- **快捷功能** - 视频演示引导，快速上手

## 🛠️ 技术栈

### 前端
- **HTML5/CSS3** - 响应式界面设计
- **JavaScript (ES6+)** - 核心交互逻辑
- **Cropper.js** - 图片裁剪功能
- **Fabric.js** - Canvas图像编辑和Logo编辑器
- **响应式布局** - 适配各种屏幕尺寸

### 后端
- **Python Flask** - Web应用框架
- **Gemini 3 Pro API** - Google AI图像处理（通过接口代理）
- **PIL/Pillow** - 图像处理库
- **OCR服务** - 文字识别功能

### 存储
- **LocalStorage** - 客户端历史记录存储
- **本地文件系统** - Logo文件管理和图片临时存储
- **ImgBB图床** - 在线图片存储（可选）

## 📦 安装与运行

### 环境要求
- Python 3.8+
- Gemini 3 Pro API密钥（通过接口代理）
- 网络连接（用于API调用）

### 快速开始

1. **克隆项目**
```bash
git clone <repository-url>
cd AI影像工作室
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **配置API密钥**
编辑 `app.py` 文件，在顶部设置API密钥：
```python
GEMINI3_PRO_API_KEY = "your_api_key_here"
```
4. **运行应用**
```bash
python app.py
```

6. **访问应用**
打开浏览器访问 `http://localhost:`

## 🎯 使用指南

### 批量Logo编辑器使用

1. **选择平台和款式**
   - 在右侧面板选择电商平台（天猫/京东/拼多多）
   - 选择Logo款式

2. **选择尺寸规格**
   - 系统会根据平台和款式显示可用尺寸
   - 选择对应的尺寸规格（如800×800）

3. **上传产品图片**
   - 点击上传区域或拖拽图片
   - 支持批量上传（最多8张）
   - 系统会自动检测图片尺寸并匹配规格

4. **选择Logo**
   - 从Logo列表中选择要添加的Logo
   - 调整Logo大小（基于图片宽度的百分比）
   - 调整Logo位置（X、Y边距）

5. **预览和调整**
   - 在画布中实时预览效果
   - 支持拖拽Logo调整位置
   - 支持缩放画布查看细节

6. **批量处理**
   - 点击"开始批量处理"按钮
   - 查看处理进度
   - 处理完成后可打包下载

### 尺寸编辑器使用

1. **上传图片**
   - 点击上传区域选择图片

2. **选择裁剪模式**
   - **自由裁剪**：手动调整裁剪区域
   - **自定义尺寸**：输入目标宽高
   - **平台规格**：选择预设的电商平台规格

3. **调整裁剪区域**
   - 在预览区域拖拽调整裁剪框
   - 实时查看裁剪结果

4. **应用裁剪**
   - 点击"应用裁剪"按钮
   - 下载裁剪后的图片

### 文字编辑器使用

1. **上传图片**
   - 点击上传区域选择图片

2. **识别文字**
   - 点击"识别文字"按钮
   - 系统会自动识别图片中的文字

3. **编辑文字**
   - 点击要修改的文字区域
   - 输入新的文字内容
   - 可以调整文字样式

4. **应用修改**
   - 点击"应用修改"按钮
   - 查看处理结果

### 批量处理使用

1. **批量背景替换**
   - 上传多张原图（最多8张）
   - 上传一张背景图
   - 点击"开始批量处理"
   - 查看进度并下载结果

2. **批量产品迁移**
   - 上传多张产品图（最多8张）
   - 上传一张场景图
   - 点击"开始批量处理"
   - 查看进度并下载结果

### AI对话模式
- 在聊天界面直接输入自然语言指令
- 例如："把这张图片的背景换成雪山"
- 支持上传图片后给出处理指令

### 历史记录
- 所有成功处理的结果自动保存到历史记录
- 支持按时间顺序浏览历史记录
- 可以重新下载或删除历史记录
- 最多保存最近50条记录

## 🔧 API接口

### 图像处理接口
- `POST /api/resize-image` - 图片尺寸调整/裁剪
- `POST /api/remove-defects` - 去瑕疵
- `POST /api/upscale` - 高清放大
- `POST /api/extract-pattern` - 产品抠图
- `POST /api/replace-text` - 文字替换
- `POST /api/replace-background` - 背景替换
- `POST /api/logo-add` - Logo添加（单张）
- `POST /api/expand-image` - 图片扩展
- `POST /api/product-migration` - 产品迁移（单张）
- `POST /api/remove-watermark` - 水印去除

### 批量处理接口
- `POST /api/batch-replace-background` - 批量背景替换
- `POST /api/batch-product-migration` - 批量产品迁移
- `GET /api/batch-progress/<task_id>` - 获取批量处理进度
- `POST /api/download-batch-zip` - 下载批量处理结果

### Logo编辑器接口
- `POST /api/logo/styles` - 获取平台下的款式列表
- `POST /api/logo/sizes` - 获取款式下的尺寸列表
- `POST /api/logo/list` - 获取尺寸下的Logo文件列表
- `POST /api/logo/compose` - 合成Logo到图片
- `POST /api/logo/export-zip` - 导出Logo处理结果ZIP

### 文字编辑接口
- `POST /api/text-recognition` - 文字识别（OCR）
- `POST /api/text-inpainting` - 文字去除（智能修复）
- `POST /api/apply-text-edits` - 应用文字编辑

### 辅助接口
- `POST /api/chat` - AI对话处理
- `POST /api/download-image` - 图片下载代理
- `POST /api/set-gemini-key` - 设置Gemini API密钥
- `GET /api/test` - 测试接口

### 静态资源路由
- `GET /LOGO/<path:filename>` - Logo文件访问
- `GET /uploads/<path:filename>` - 上传文件访问
- `GET /fonts/<path:filename>` - 字体文件访问

## 🚨 注意事项

### 文件限制
- 单张图片建议不超过10MB
- 批量处理最多8张图片
- 支持格式: JPG, PNG, WebP等常见图片格式

### API限制
- 需要有效的Gemini 3 Pro API密钥
- 注意API调用频率限制
- 处理时间取决于图片复杂度和API响应速度
- 大图片处理可能需要较长时间（最长5分钟）

### Logo文件要求
- Logo文件需要按照指定目录结构组织
- 支持PNG格式，建议使用透明背景
- 文件名格式建议：`{尺寸}-{编号}-{颜色}.png`

### 隐私安全
- 图片处理过程中会发送到第三方AI服务
- 敏感图片请谨慎使用
- 历史记录仅存储在本地浏览器中
- 建议在生产环境中使用HTTPS
